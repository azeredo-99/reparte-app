# Reparte

Diz quanto recebeste este mês e o Reparte diz-te quanto reservar para despesas, poupança, investimento, lazer e atividades.

**Abrir e instalar:** https://azeredo-99.github.io/reparte-app/

- Android / Chrome / Edge: abre o link e toca em **Instalar app**.
- iPhone: abre no Safari → **Partilhar** → **Adicionar ao ecrã principal**.

Os teus dados ficam apenas no teu dispositivo.
